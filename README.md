# Excelano Homebrew Tap

This tap is retired and holds no formulae. Excelano's command-line tools install
from the [Excelano apt repository](https://excelano.com/apt/), from winget on
Windows, and as prebuilt binaries on each project's GitHub releases. Slipcase
Open for macOS is a notarized download on its
[releases page](https://github.com/excelano/slipcase-open/releases/latest).

If you tapped it, remove it with:

```sh
brew untap excelano/tap
```
